## Contribution process (each member)

1. `git pull` the latest `main`, create `feat/<area>-<name>`.
2. Read your area's code and the matching rows of [REQUIREMENTS_MATRIX](REQUIREMENTS_MATRIX.md).
3. Run your area's checks (below) and record what you observe, including failures.
4. Make real fixes, improvements, tests or documentation; commit them yourself.
5. Open a pull request describing what changed and how you checked it; another member reviews it.
6. Add a line to your section below with links.
